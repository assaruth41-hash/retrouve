# Retrouve

Site web de récupération d'objets perdus. Une personne qui trouve un objet le publie avec une photo, le lieu et son numéro. Le propriétaire le retrouve dans la liste et échange avec elle grâce à un chat en direct.

**Site en ligne :** https://assaruth41-hash.github.io/retrouve

## Fonctionnalités
- Publication d'un objet trouvé (nom, lieu, numéro, photo)
- Liste des objets trouvés, partagée entre tous les visiteurs
- Chat en direct entre le trouveur et le propriétaire
- Scène 3D animée en page d'accueil

## Technologies
- **HTML et CSS** pour la vitrine et le design
- **JavaScript** pour le fonctionnement du site
- **Three.js** pour la scène 3D
- **Supabase** pour la base de données, le stockage des photos et le chat en temps réel
- **GitHub Pages** pour l'hébergement

## Limites actuelles
Projet d'apprentissage : il n'y a pas encore de connexion par compte. À venir : authentification par e-mail pour protéger les numéros de téléphone et les conversations.
